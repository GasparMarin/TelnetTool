# TelnetTool

Cliente Telnet sencillo para Android.

- Campo para IP o hostname y campo para el puerto (por defecto 23).
- Boton Conectar / Desconectar.
- Consola para ver lo que envia el servidor y una caja para escribir comandos.

## Compilar

Abrir el proyecto con Android Studio, o desde terminal:

```bash
./gradlew assembleDebug
```

El APK queda en `app/build/outputs/apk/debug/`.
